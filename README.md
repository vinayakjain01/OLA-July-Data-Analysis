# OLA July Data Analysis

🚖 OLA July Data Analysis
📌 Project Overview
This project focuses on analyzing OLA ride booking data for July to uncover trends, patterns, and business insights. Using SQL for data querying and Power BI for visualization, the goal was to identify factors influencing bookings, cancellations, revenue, and customer satisfaction.

🎯 Objectives
Analyze booking patterns and ride volumes.

Identify peak hours, popular ride categories, and high-demand days.

Understand cancellation trends and their potential causes.

Measure revenue contribution by ride type and location.

Provide actionable insights for operational improvements.

🔍 Key Insights
Peak Hours: Majority of rides occur between 8–10 AM and 6–8 PM, indicating work commute patterns.

Popular Ride Category: Prime Sedan generated the highest revenue despite fewer trips compared to Mini.

Cancellations: Driver cancellations were more frequent than customer cancellations.

High-Demand Days: Fridays and Saturdays saw the highest ride volume.

Revenue Trends: Average ride fare increased by 12% during weekends.
